# Decisions: Veil Ecosystem

## ADR Log

| Date | Decision | Rationale |
|---|---|---|
| 2026-08-24 | Initial scaffold as factory-output, privacy `public` (+ private sibling `veil-ecosystem-private`) | Master architecture repo for the VeilGremlin product family, following the same public/private-sibling split as veil-foundations. Sourced directly from a full ecosystem audit run 2026-08-22, which named "no document ties the five repos together" as its final open seam. |
| 2026-08-24 | `docs/architecture.md` written in this session, not deferred to a separate Fable design pass | Unlike dark-lab's greenfield architecture (which needed net-new design), this repo's job is synthesising design decisions and status that already exist and are well-documented across the five component repos' own decision logs and the audit — a synthesis task, not a novel design one. |
| 2026-08-24 | `docs/setup.md` documents per-component run instructions "as-is," explicitly not an aspirational docker-compose for the integrated end-state | Only 1 of 5 designed cross-repo integrations (veil-proxy → veil-demo) is actually wired as of the 2026-08-22 audit; an orchestration script implying a working integrated system would misrepresent that. |
| 2026-08-24 | Ran a doubt-driven-development review cycle on the first draft of `docs/architecture.md`/`docs/setup.md` before merging; corrected three false claims it found | The first draft was synthesised from the 2026-08-22 audit and never independently re-checked against live repo state before publishing, despite claiming "as of 2026-08-24" currency. A fresh-context reviewer (tool-verified: ran `cargo test`, read git log, read ADR text) plus a second, narrower Codex pass found: (1) the veil-foundations Guardrail-mandatory defect this doc named as its one specific defect was already fixed by ADR-010 on 2026-08-23, the day *before* this doc's stated date; (2) veil-custodian's HTTP service, claimed "100% unbuilt," had a real axum+Postgres+mTLS service land 2026-08-23; (3) veil-proxy's `TelemetryEvent` type, claimed nonexistent, had landed 2026-08-23/24 (what's actually still missing is the network emitter, not the type). Also wrong: veil-proxy's test count (claimed 270, actually 381), veil-custodian's audit-log line count (claimed 539, actually 745), and two of five setup.md command sequences (missing `terraform init`; missing the `DATABASE_URL` requirement for veil-custodian's Postgres-backed tests). See git history on branch `agent/claude/architecture-doc` for the corrected text. |
